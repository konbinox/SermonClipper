# SermonClipper
# 🎤 讲道精华提取系统

自动提取讲道精华，生成 8-10 分钟短视频。

## 📥 下载

请到 [Releases](https://github.com/你的用户名/SermonClipper/releases) 页面下载最新版本。

## 🚀 使用方法

1. 双击运行 `SermonClipper.exe`
2. 输入 YouTube 链接或本地视频路径
3. 选择讲道人（或输入）
4. 输入讲道题目
5. 选择经文（书卷+章节）
6. 输入讲解提纲（每点一行）
7. 点击生成，等待完成

## 📦 系统要求

- Windows 10/11
- 4GB 以上内存
- 1GB 硬盘空间
