# 🎤 讲道精华提取系统

自动提取讲道精华，生成 8-10 分钟短视频。

## 🚀 使用说明

### 第一步：安装依赖（首次运行需要）

双击运行 `SermonClipper.exe` 后，如果提示缺少依赖，请打开命令提示符（CMD）或 PowerShell，运行：

```bash
pip install faster-whisper zhconv
```

### 第二步：运行程序

双击 `SermonClipper.exe` 打开主界面。

### 第三步：填写信息

| 字段 | 说明 |
|------|------|
| **视频来源** | 粘贴 YouTube 链接 或 输入本地视频路径 |
| **讲道人** | 从下拉列表选择，选"其他"可手动输入 |
| **讲道题目** | 必填，输入讲道标题 |
| **经文选择** | 选择书卷、章节、节号，点击"+ 添加经文" |
| **讲解提纲** | 每点一行，至少输入一个要点 |
| **字幕语言** | 选择简体中文 / 繁体中文 / 无字幕 |
| **视频时长** | 选择 3-5 / 6-8 / 8-10 / 10-15 分钟 |

### 第四步：生成视频

点击 **"▶ 生成精华视频"** 按钮，等待处理完成（约 5-10 分钟）。

完成后会在程序所在目录的 `output` 文件夹中生成视频文件。

## ❓ 常见问题

### 1. 提示 "找不到 faster_whisper"

请运行以下命令安装依赖：
```bash
pip install faster-whisper zhconv
```

### 2. 提示 "ffmpeg 未找到"

请下载 ffmpeg 并添加到系统 PATH：
- 下载地址：https://ffmpeg.org/download.html
- 或使用包管理器：`choco install ffmpeg`

### 3. 生成失败或视频时长不对

请检查：
- 视频文件是否完整
- 转录文件是否正常（`output/transcript.json`）
- 如有问题，删除 `output` 文件夹重试

### 4. exe 文件太大（约 860MB）

因为内置了 AI 转录模型。首次运行需要下载模型，之后会自动缓存。
